# 系统设置功能使用说明

## 功能概述

系统设置功能包含多个模块，允许用户自定义应用的各种功能，包括显示设置、智能体通信设置、工具标签过滤等。该功能通过右上角的"系统设置"按钮访问，所有设置会自动保存并在下次访问时恢复。

## 功能特性

### 1. 显示设置

#### 外观主题
- **浅色**: 使用浅色主题
- **深色**: 使用深色主题
- **系统**: 根据系统偏好自动切换主题

#### 字体大小调节
- **小**: 14px 字体大小
- **中**: 16px 字体大小（默认）
- **大**: 18px 字体大小

#### 布局模式
- **舒适模式**: 使用标准间距和布局
- **紧凑模式**: 减少间距，显示更多内容

#### 其他显示选项
- **动画效果**: 启用/禁用界面过渡动画
- **紧凑模式**: 进一步减少组件间距和内边距

### 2. 智能体通信设置

#### 通信协议
- **HTTP**: 标准HTTP请求（适用于简单交互）
- **SSE**: 服务器发送事件（适用于实时数据流）
- **WebSocket**: 双向通信（适用于复杂交互）

#### 响应模式
- **同步模式**: 发送请求后等待完整响应
- **流式模式**: 实时接收响应流，支持工具调用可视化

### 3. 工具标签过滤

- 基于标签筛选可用工具
- 支持多标签组合过滤
- 提供标签搜索功能
- 工具标签选择会直接影响智能体可调用的工具

### 4. 系统信息

显示应用的基本信息：
- 版本号
- 环境（开发版/生产版）
- 缓存状态

### 5. 恢复默认设置
一键将所有系统设置恢复到默认状态。

## 技术实现

### 状态管理
系统设置使用 Zustand 进行状态管理，分为多个独立的 store：
- `displayStore.js`: 管理显示相关设置
- `agentStore.js`: 管理智能体通信和工具标签设置

### 组件结构
- `SystemSettings.jsx`: 系统设置主组件，采用抽屉式设计
- `ProtocolSelector.jsx`: 通信协议选择器组件
- `ToolTagSelector.jsx`: 工具标签选择器组件

## 使用方法

1. 点击右上角的"系统设置"按钮（齿轮图标）
2. 在弹出的设置抽屉中切换到相应的设置类别
3. 调整所需的设置项
4. 设置会自动保存并在页面刷新后保持
5. 可以随时点击"恢复默认设置"按钮重置所有设置

## 开发指南

### 添加新的设置模块

1. 创建新的设置组件（如 `NewSettingsModule.jsx`）
2. 如需独立存储，创建对应的 Zustand store
3. 在 `SystemSettings.jsx` 中导入并添加新模块
4. 确保新模块遵循现有的UI设计语言

### 扩展智能体通信设置

1. 在 `ProtocolSelector.jsx` 中添加新的协议选项
2. 在 `agentService.js` 中实现对应的通信方法
3. 更新 `agentStore.js` 以支持新协议

### 扩展工具标签过滤器

1. 确保工具在注册时包含正确的标签信息
2. 修改 `ToolTagSelector.jsx` 以支持新的筛选逻辑
3. 更新 `agentStore.js` 中的过滤方法

## 注意事项

1. 所有设置都存储在浏览器的 localStorage 中
2. 设置仅影响当前用户的界面和功能，不影响其他用户
3. 某些协议和模式组合不可用（如 HTTP 协议不支持流式模式）
4. 工具标签过滤会直接影响智能体的功能范围
5. 系统设置抽屉在移动设备上会占据整个屏幕
